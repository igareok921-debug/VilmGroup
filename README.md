# Vilm Group Site

Website-ul oficial Vilm Group.

## Development

```bash
npm run dev
```

Deschide `http://localhost:3000` in browser.

## Build

```bash
npm run build
```

## SEO

Site-ul foloseste domeniul canonic `https://www.vilmgroup.md`, sitemap, metadata localizata si faviconuri dedicate Vilm Group.

## Environment

Variabilele locale se tin in `.env.local`.
