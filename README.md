# Vilm Group Site

Website-ul oficial Vilm Group.

## Development

```bash
npm run dev
```

Deschide `http://localhost:3000` in browser.

## Build

```bash
npm run build
```

## SEO

Site-ul folosește domeniul canonic `https://vilmgroup.md`, sitemap, metadata localizată și faviconuri dedicate Vilm Group.

## Environment

Variabilele locale se tin in `.env.local`.
